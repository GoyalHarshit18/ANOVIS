## 4. PAT Verification
- **Input**: 24h measurements (`Iddq_uA_24h`, `Leakage_nA_24h`, `PropDelay_ns_24h`).
- **Calculation**: Computes a modified Z-score using `median` and `mad` stored in `pat_reference.pkl`.
- **Output**: Returns a dictionary where `"score"` acts as `PAT_Risk`. 

## 5. Peer Verification
- **Input**: 0h and 24h measurements.
- **Calculation**: Scales 0h data, finds neighbors using `peer_knn.pkl`, gets expected 24h values, calculates residual against actual 24h, normalizes with `peer_scales.pkl`.
- **Output**: Returns a dictionary where `"score"` acts as `Peer_Risk`.

## 6. Temporal Verification
- **Input**: 0h and 24h measurements.
- **Calculation**: Computes relative drift and compares to median and scale in `temporal_reference.pkl` to produce a z-score.
- **Output**: Returns a dictionary where `"score"` acts as `Temporal_Risk`.

## 7. Isolation Forest Verification
- **Input**: 12 features generated from 0h/24h and calculated drift/slopes.
- **Calculation**: Preprocesses with `if_scaler.pkl`, predicts using `isolation_forest.pkl`.
- **Output**: Returns a dictionary where `"score"` acts as `IF_Risk`.

## 8. Module A Pipeline
`screening_service.py` coordinates the engines.
Measurements → `compute_pat`, `compute_peer_analysis`, `compute_temporal_analysis`, `compute_isolation_forest`.
The outputs are combined in `risk_fusion.py` (`compute_a_score`).
